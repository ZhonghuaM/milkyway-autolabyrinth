# Milky Way Idle Auto Labyrinth

Playwright-based automation script for Milky Way Idle labyrinth runs.

## Files
- `milkyway_autolabyrinth.py`: main automation script
- `accounts.example.json`: example account config
- `diagnose_labyrinth_escape.py`: optional escape-debug helper
- `inspect_escape_dialog.py`: optional dialog inspection helper

## Notes
- Do not commit browser state files or real account config files.
- This repository is for labyrinth automation only.
